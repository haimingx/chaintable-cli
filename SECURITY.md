# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/haimingx/chaintable-cli/security/advisories/new). Do not open a public issue.

Include the `chaintable version` output, the platform, the steps to reproduce and the impact. Never include a real token or API key; if one was exposed, revoke it on chaintable.com first.

You will get a reply within 7 days. Fixes ship in a new release, and the advisory is published once users can upgrade.

## Scope

This repository covers the `chaintable` binaries, the install script and the agent skill. Vulnerabilities in the Chaintable service itself belong to its operator, not to this project.

## Supported versions

Only the newest release receives fixes.
